MMORPG 통합 표준 데이터 모델 설계 및 BI 솔루션 구축
2022.07 ~ 2023.06 (약 1년) | DW 모델링 / BI | 넷마블
게임별 파편화된 분석 모델을 Star Schema 기반 통합 표준 모델로 전환, 오픈소스 BI 도입으로 업무 50% 단축 및 비용 절감 달성
배경 및 문제 정의
  • 게임별 분석가가 각자 대시보드·리포트용 데이터 모델을 별도 구성, 유료 BI 솔루션 사용
  • 동일 분석 지표를 타 게임에 적용 시 스키마 불일치로 매번 별도 구성 필요 → 과도한 공수 발생
  • 업무 공백 시 파편화된 스키마로 인해 타 구성원 백업 불가
사용 기술
BigQuery Dataform Apache Airflow Apache Superset Cloud SQL (PostgreSQL) SQL / Python / Java / JavaScript
주요 구현 사항
  • 전 게임 공통 사용 영역 정의 및 표준 스키마 설계 (가변 속성 코드화)
  • BigQuery 최적화 단일 테이블 연산 중심 모델 구조 정의
  • Dataform & Airflow 파이프라인 retry 정책 적용, 모니터링 알람 도입
  • 검증/상용 서버 간 단일 Cloud SQL 공유 아키텍처 설계 및 구현
  • MMORPG 7개 게임 대시보드 구현 (대시보드당 20개+ 차트)
성과 및 개선 효과
영역BeforeAfter개선 효과
업무 시간 신규 게임/기능마다 별도 스키마 구성 표준 모델 기반 소스 재활용 약 50% 단축달성
데이터 처리 속도 다중 테이블 조인 연산 BigQuery 단일 테이블 연산 처리 속도 2배 향상달성
BI 운영 비용 유료 BI 솔루션 라이선스 Apache Superset 오픈소스 전환 라이선스 비용 절감

카카오페이증권 전사 주요 조직 KPI 대시보드 구축
2025.12 ~ 2026.04 | BI | 카카오페이증권
전사 수준 KPI 현황을 경영진·각 조직에 매일 공유하는 통합 대시보드 구축 — 표준 지표 기준 적용으로 데이터 신뢰도 확보
배경 및 문제 정의
  • 전사 수준 도메인별 KPI 대시보드 부재, 부서별 혼재된 지표 기준 사용
  • 경영회의 시 부서마다 다른 수치 제시로 신뢰도 논란 발생
  • 마감 보고 준비 시간 과다 소요
사용 기술
MSTR(MicroStrategy) Impala / Hive / Trino Apache Airflow Confluence SQL
대시보드 구성
  • 경영 요약 / 서비스별 KPI 드릴다운 / 마케팅·고객 현황
  • 달성률: Gauge/Bullet Chart, 추이: Line + Bar 혼합, 고객 현황: Funnel Chart
  • 매일 오전 자동 갱신 (전일 기준)
성과 및 개선 효과
영역BeforeAfter개선 효과
전사 KPI 현황 전사 수준 KPI 대시보드 없음 경영진·각 조직 일별 자동 공유 KPI 현황 실시간 가시성 확보
데이터 신뢰도 부서별 상이한 지표 기준 표준 지표 기준 적용 이후 수치 이의 제기 없이 안정적 운영

카카오페이증권 전사 KPI 지표 기준 정의 위원회
2025.04 ~ 현재 | 전사 데이터 거버넌스 체계 구축 | 카카오페이증권
부서별 상이한 지표 기준을 전사 표준으로 통일하는 위원회 운영 — 경영회의 수치 불일치 문제 근본 해결
배경 및 문제 정의
  • 부서별 상이한 지표 산출 기준으로 경영회의 시 동일 지표에 대한 복수 버전 수치 제시
  • 의사결정 신뢰도 저하, 데이터 리터러시 부재
  • 수치 논란으로 경영회의 효율 저하
주요 구현 사항
  • 위원회 공식화 및 이해관계자 합의 프로세스 도입
  • 전사 표준 지표 정의서 작성 및 배포 (지표 용어 표준화 가이드 포함)
  • 부서 협의체 운영 및 지표 기준 합의 주도
  • 지표 정의서 검토·승인 체계 수립 및 정기 업데이트 운영 체계 구축
성과 및 개선 효과
영역BeforeAfter개선 효과
경영회의 수치 신뢰도 부서별 상이한 수치, 이의 제기 빈번 전사 표준 지표 기준 통일 이후 수치 이의 제기 없이 안정적 운영달성
데이터 리터러시 지표 기준 부재, 부서별 임의 산출 표준 지표 정의서 배포 및 용어 가이드 전사 데이터 리터러시 확대 기반 마련

Databricks Notebook SQL / Python Google Sheet

CRM 운영 기준 직관 기반 발송 빈도 관리 데이터 기반 임계치 및 운영 가이드라인 제시 근거 기반 운영 의사결정 가능

MMORPG 게임 유저 이탈 예측 모델 개발
2021.06 ~ 2021.11 | 데이터 분석 / ML | 넷마블
기존 획일적 이탈 기준을 유저 그룹별로 재정의하고 ML 기반 이탈 예측 스코어 지표 개발 — 업데이트 후 모니터링 지표로 활용
배경 및 문제 정의
  • 회사 내 게임 장르 구분 없이 공통 이탈 기준 적용 중
  • 공통 기준이 MMORPG 장르 특성 및 유저 특성(과금/무과금)을 반영하지 못해 이탈 감지 정확도 낮음
사용 기술
BigQuery BigQuery ML Python (K-means, GLM, XGBoost, Random Forest) Jupyter Notebook Google Data Studio
분석 방법
  • K-means Clustering → 유저 그룹별 Moving Average 기반 이탈 구간 정의
  • GLM / XGBoost / Random Forest 이탈 예측 모델 개발 및 비교
  • 일 배치 이탈 예측 스코어 대시보드 구축 (Data Studio)
성과 및 개선 효과
영역BeforeAfter개선 효과
이탈 기준 장르·유저 특성 무관한 단일 기준 유저 그룹별 차별화된 이탈 구간 정의 이탈 감지 정확도 향상달성
이탈 감지 방식 사후 이탈 확인 개인별 이탈 예측 스코어 일 배치 제공 사전 감지 및 업데이트 후 모니터링 지표로 활용
